# 基于 51 单片机的 TEC 温度控制系统

## 设计要求

左侧 4 位动态数码管显示设定温度，右侧 4 位动态数码管显示 DS18B20 采集到的实际温度。

- 按键 1：设定温度上调。
- 按键 2：设定温度下调。
- 当实际温度大于设定温度 0.5℃ 时，TEC 开始工作。
- 当实际温度小于设定温度 0.5℃ 时，TEC 停止工作。

## 所需元器件

- 普中科技 V5.5 开发板（单片机控制平台）
- TEC 制冷模块
- DS18B20 温度传感器
- 散热风扇
- 可调电源
- 其他必要配件

## 实现功能

- DS18B20 通过单总线读取温度，包含传感器存在检测、异常值排除和简单滤波。
- LCD1602 显示设定温度、当前温度、暂停状态与 TEC 累计工作时间。
- 按键以 0.5℃ 为步进调节设定温度，并支持暂停/恢复全部控制输出。
- 采用 ±0.5℃ 回差控制，减少制冷模块或继电器的频繁动作。
- 温度超限时启动 TEC 并进行蜂鸣报警；达到阈值后停止工作。
- 红、绿 LED 用于显示 TEC 的工作/停止状态。
- 定时器 0 每 500 μs 中断，用于蜂鸣器音调和工作时间累计。
